# cp437.h — display glyph lookup

This file contains 128 UTF-8 string literals for CP437 byte values 128–255.
It has no functions, include guard or public declarations: host.c includes it
inside the `high` array initializer used by `glyph()`.

For a legacy character `c`, `high[c - 128]` selects the printable UTF-8 bytes.
For example, CP437 219 maps to `█` and 178 to `▓`. These are extended CP437
codes, not ASCII characters (ASCII ends at 127). The scrollbar retains the
legacy style while outputting valid Unicode to the terminal.

The reverse conversion is separate: `utf8_to_cp437()` in utf8.c maps a Unicode
code point back to a byte when editing legacy content. One table describes
output strings; the other supports input conversion. Keep their mappings
consistent if changing supported characters, and do not confuse either with
full-file encoding conversion or terminal font guarantees.
